# 분석 보고서

케어퐁 스트레스 모델의 방법, 검증, 수치를 한곳에 모은 문서.

- 프로젝트 종료 시점(2026-11)에 작성한 종합 보고서의 내용을 옮김.
- 수집 데이터 수치는 2026-11-02~03 재추출 스냅샷(31명, 유효 라벨 157건) 기준임. 다른 스냅샷 값은 따로 표시함.
- 수치는 분석 당시 기록한 값임. 이 저장소 코드로 다시 계산되는 범위는 [04_reproducibility.md](04_reproducibility.md)에 있음.
- 원본 보고서의 그림은 싣지 않음. 수집 데이터에서 그린 것이 섞여 있어 제외함.
- 계정 식별자, 접속 정보, 원시 측정값은 싣지 않음.

## 2. 설계

### 세 가지 신호

| 채널 | 신호 | 보는 것 |
|---|---|---|
| 행동 | 키보드·마우스 | 본인이 의식하지 못하는 업무 부하 |
| 자가보고 | 예/아니오, 강도 1~5 | 본인이 느끼는 스트레스 |
| 신체 | HRV (손끝 PPG) | 생리 반응 |

### 2층 구조

| 층 | 신호 | 측정 대상 | 데이터 | 역할 |
|---|---|---|---|---|
| 1차 | 키보드·마우스 | 업무 부하 | SWELL-KW, 수집 데이터 | 상시 선별 |
| 2차 | 손끝 PPG | 생리적 스트레스 | MAUS | 확인 |

- 업무 부하는 스트레스의 상류 요인임(Karasek 직무요구-통제 모형).
- 부하가 스트레스로 이어지는 정도는 개인의 해석을 거치므로 사람마다 다름(Lazarus & Folkman 1984).
- 그래서 부하는 행동으로 재고, 개인차는 개인화로 보정하고, 생리 반응은 HRV로 따로 잼.
- SWELL 논문에서도 스트레스 요인을 가했을 때 자가보고 변화는 작았고 키·마우스 지표는 유의하게 변했음. 키·마우스는 "느낀 스트레스"가 아니라 "업무 부하"를 재는 신호로 봄.

## 3. 키보드·마우스 모델 (SWELL-KW)

### 3.1 데이터

- SWELL-KW (Koldijk et al., ICMI 2014). 지식노동자 25명이 사무 업무를 하는 동안 이메일 방해와 시간 압박을 조작함.
- 기록: 키·마우스, 표정, 자세, 심박, 피부전도. 설문(NASA-TLX 등).
- 전체 172개 컬럼 중 서비스에서 상시 수집할 수 있는 컴퓨터 상호작용 지표만 사용함.

### 3.2 피처 16개

키보드 9개

| 피처 | 의미 |
|---|---|
| `SnKeyStrokes` | 전체 키 입력 수 |
| `SnChars` | 글자 키 수 |
| `SnSpecialKeys` | 특수키 수 |
| `SnDirectionKeys` | 방향키 수 |
| `SnErrorKeys` | 수정키 수 (Backspace, Delete) |
| `SnShortcutKeys` | 단축키 수 |
| `SnSpaces` | 스페이스 수 |
| `CharactersRatio` | 글자 수 ÷ 전체 키 수 |
| `ErrorKeyRatio` | 수정키 수 ÷ (글자 + 스페이스) |

마우스 7개

| 피처 | 의미 |
|---|---|
| `SnMouseAct` | 마우스 이벤트 수 |
| `SnLeftClicked` | 좌클릭 수 |
| `SnRightClicked` | 우클릭 수 |
| `SnDoubleClicked` | 더블클릭 수 |
| `SnWheel` | 휠 스크롤 수 |
| `SnDragged` | 드래그 수 |
| `SnMouseDistance` | 이동 거리 |

- 제외: 표정과 자세(상시 촬영 필요), 생체 신호(2차 층에서 다룸), 설문(라벨), 앱 전환 2개(창 제목 접근 필요).
- 수집기는 키 종류별 개수와 시각만 저장하고 어떤 글자인지는 저장하지 않음. 그래서 언어별 분석은 할 수 없음.

### 3.3 전처리

- 분할: 사람 단위. 같은 사람이 학습과 평가에 함께 들어가지 않게 함.
- 결측: 약 1%. 중앙값으로 대체. 이동 거리 최대값이 81,098이라 평균은 왜곡됨.
- 이상값: 더블클릭, 방향키, 우클릭은 대부분 0인 분포라 IQR 기준이 정상값을 이상값으로 표시함. 제거하지 않음.
- 표준화: 변수 간 스케일 차이가 커서 평균 0, 표준편차 1로 맞춤.

### 3.4 피처와 라벨의 관계 (수집 데이터 라벨 252건)

상관

- 16개 피처 모두 점이연 상관 |r| ≤ 0.15. 0.3을 넘는 피처는 없음.
- SWELL에서 보고된 값(|r| ≤ 0.137)과 같은 수준임.
- 상호정보량도 최대 0.13. 비선형 관계로 봐도 개별 피처는 약함.
- 피처 간 상관: 키보드 입력량 계열끼리 ρ 0.7~0.9, 마우스 계열끼리 0.5~0.9(휠과 마우스 활동 0.9), 키보드와 마우스 사이는 0에 가까움.
- PCA: 첫 두 축이 분산의 45%를 설명함. 90%를 담으려면 9개 축이 필요함.
- 합계 변수(`SnKeyStrokes`)는 하위 항목의 합이라 VIF가 무한대임. 예측 목적이라 변수를 빼지 않음.

집단 비교 (스트레스 133건, 여유 119건)

- Shapiro 검정에서 16개 모두 비정규. Mann-Whitney 검정을 사용함.

| 피처 | 여유 → 스트레스 (평균) | MW p | FDR q | Cohen's d | Cliff's δ |
|---|---|---|---|---|---|
| 스페이스 | 2.8 → 4.6 | 0.004 | 0.060 | 0.25 | 0.19 |
| 글자 비율 | 0.29 → 0.39 | 0.028 | 0.075 | 0.29 | 0.15 |
| 우클릭 | 0.3 → 0.6 | 0.024 | 0.077 | 0.23 | 0.11 |
| 더블클릭 | 0.9 → 1.2 | 0.023 | 0.093 | 0.17 | 0.15 |
| 수정키 | 5.0 → 6.9 | 0.042 | 0.096 | 0.17 | 0.14 |
| 글자 수 | 32 → 40 | 0.014 | 0.115 | 0.12 | 0.17 |
| 키 입력 수 | 50 → 62 | 0.023 | 0.123 | 0.14 | 0.16 |
| 휠 | 34 → 22 | 0.279 | 0.344 | -0.30 | -0.08 |

- 보정 전 p < 0.05는 7개. FDR 보정 후 q < 0.05는 0개, q < 0.10은 5개.
- 효과크기는 모두 작음(Cohen's d 0.1~0.3, Cliff's δ 0.19 이하).
- 방향은 일관됨: 스트레스 응답 구간에서 타이핑, 클릭, 수정키가 늘고 휠과 이동이 줆.
- 개인 단위(17명, 사용자별 평균과 개인 "예" 비율의 Spearman 상관)로 올리면 유의한 피처는 0개.

팝업 트리거와 응답

| 트리거 | "예" 비율 |
|---|---|
| 과부하 감지(spike) | 62.2% (79/127) |
| 무작위(random) | 50.7% (73/144) |

- 차이 +11.5%p, χ² = 3.18, p = 0.075.
- 과부하 트리거는 활동이 많을 때 뜨므로, 팝업이 뜬 1분 창의 활동 피처가 라벨을 일부 설명함. 1분 창 성능을 대표값으로 쓰지 않는 이유임(4.4).

### 3.5 피처 선정

| 조합 | AUC |
|---|---|
| 키보드만 | 0.578 |
| 마우스만 | 0.579 |
| 유의한 11개 | 0.617 |
| 16개 전부 | 0.634 |

- 유의하지 않은 5개(수정키 비율, 더블클릭, 휠, 드래그, 이동 거리)도 합치면 기여함.
- 상관 상위만 고르면 평가 데이터를 보고 변수를 고르는 것이 되어 16개를 전부 씀.

### 3.6 모델과 판정

- 표준화, 로지스틱 회귀, Isotonic 확률 보정, 0~100 지수.
- 로지스틱 회귀를 쓴 이유
  - 개별 피처가 약하고 선형 결합에서 신호가 모이는 구조임.
  - 계수의 부호와 크기로 해석할 수 있음.
  - 계수만으로 추론이 됨(추론 약 0.006ms).
  - 모델 8종을 비교해도 0.6대를 넘지 못함.
- 구간: 50 미만 낮음, 50~63 중간, 63 이상 높음.
- 개입 컷 63은 Youden's J 최대점이고, 헛경보율 20% 이하 기준과 같은 지점임.
- 알람: 매 1분마다 직전 30개 창 중 지수 63 이상인 창이 20개 이상이면 발화. 연속이 아니라 누적으로 셈.
  - 30분: 정신 피로가 지속 인지부하로 누적되는 시간(Trejo 2015).
  - 30, 20, 63은 문헌 기반 초기값이며 수집 데이터로 다시 조정할 값임.
- 성능: SWELL 사람 단위 교차검증 AUC 0.63.

### 4.3 처리 계층 교차 확인 (Athena)

원본과 별개로, 운영 파이프라인이 만든 처리 테이블을 따로 조회해 같은 문제가 남아 있는지 확인함.

- 중복: 140,560건 중 사용자·분 조합은 32,682건. 76.7%가 중복이고 한 분에 최대 421건. ETL이 중복을 제거하지 않아 처리 테이블까지 전파됨. 원본의 44.2%와 값이 다른 것은 계층과 시점이 달라서임.
- 품질 표시: 전체가 타이밍 불완전, 계산 버전 미검증 상태. 동적 피처 부분 계산 32.6%, 창 시작 시각 겹침 26.8%, 라벨 창 매칭 실패 6.1%.
- 사용자별 분포: 상위 3명이 창의 약 93%(47,428 + 42,113 + 41,584)를 차지하는데 평균 타이핑은 1.7~3.1로 가장 낮음. 활발히 입력한 사용자(평균 22~27)는 창이 46~107개뿐임.
- 사용자 간 평균 타이핑 16배(1.6~26.7), 평균 마우스 90배(0.4~36.6) 차이.
- 창 수와 입력량의 역상관은 다중 전송 때문이었음. 한 계정은 창 21,408개에 평균 타이핑 26이었고, 중복 제거 후 창 1,826개(91% 제거), 평균 타이핑 149가 됨. 전체는 53,272에서 27,458(48.5% 중복).

|---|---|---|
| 1분 창 | 0.629 | 0.497 |
| 30분 평균 + 개인화 | 0.612 | 0.589 |

- 1분 창의 0.629는 과부하 트리거에서 온 값임. 무작위 트리거만 보면 우연 수준임.
- 30분 평균과 개인화 단계는 무작위 트리거만으로도 0.589임.

운영점에서의 성능 (out-of-fold, n=178, "예" 비율 0.39)

| 운영점 | 임계 확률 | 정밀도 | 민감도 | 특이도 | 헛경보율 | 알람 비율 | TP·FP·FN·TN |
|---|---|---|---|---|---|---|---|
| Youden 최적 | 0.48 | 0.51 | 0.62 | 0.61 | 0.39 | 0.48 | 43·42·26·67 |
| 헛경보율 20% 이하 | 0.62 | 0.52 | 0.35 | 0.80 | 0.20 | 0.26 | 24·22·45·87 |

- 헛경보율을 20%에 맞추면 "예" 응답의 35%만 잡음. 행동 신호는 단독 판정이 아니라 측정을 권하는 계기로 씀.

### 4.5 피처 중요도, 시간대, 유의성

- 순열 중요도: 스페이스, 키 입력, 휠, 클릭 등 활동량 계열이 상위. SWELL 분석과 방향이 같음.
- 시간대: 활동이 9시~18시 30분에 몰리고 13시에 가장 낮음.
- 15시 창 수가 13,294로 튀었는데 그중 70%가 계정 하나의 다중 전송이었음. 정리 후 3,206.
- 시간대별 활동량과 "예" 비율의 상관 r = -0.08. 15시는 활동량이 가장 많지만 "예" 비율은 낮고, 16시와 18시는 반대임. 16시와 18시는 응답이 약 11건이라 탐색적 수준임.
- 순열검정 p = 0.10. 31명으로는 통계적으로 유의하다고 말할 수 없음. 0.62가 0.5보다 높고 방향이 SWELL과 같다는 정도임.

### 4.6 리듬 파생변수 폐기

원시 키 이벤트(ms 단위 시각)에서 37개를 만들어 추가해 봄. 키 간격의 분포, 백분위, 엔트로피, 자기상관, 버스트, 멈춤, 즉시 교정 비율, 속도 변동계수.

## 5. 개인화

### 5.1 필요한 이유

- 사용자마다 평소 타이핑량이 다름. 기준선을 낼 수 있었던 19명(기록 100개 이상) 사이에서 평균이 약 7배 차이남. 초기 스냅샷에서는 14배.
- 절대값으로 판정하면 많이 치는 사람이 계속 과부하로 나옴.

### 5.2 식

```
z = (x - mu_eff) / sigma
mu_eff = w * (개인 평균) + (1 - w) * (전체 평균)
w = n / (n + k)
```

- 중심은 개인 쪽으로 옮기고, 나누는 표준편차는 전체 값을 씀. 개인 표준편차는 기록이 적을 때 불안정함.
- n이 커지면 w가 1에 가까워짐. 모델을 다시 학습하지 않아도 개인화가 강해짐.
- 기준선이 없는 사용자는 w = 0으로 전체 값에서 시작함.

### 5.3 키보드·마우스

- 야간 배치가 사용자별 평균, 표준편차, n과 전체 기준을 갱신하고, 판정 시점에는 직전 30분 활동 창 평균을 읽어 변환만 함.
- 전체 기준은 사람별 평균을 먼저 낸 뒤 평균함. 기록이 많은 사용자에게 쏠리지 않게 함.
- k = 300. 하루 활동 창 약 135개 기준으로 2일이면 개인과 전체가 반반, 2주면 약 86%.
- k는 평가 AUC를 보고 고른 값이 아님. "안정되는 데 필요한 관측 수(약 2일)"라는 사전 기준으로 정함.
- 저장소에는 변환 함수(`keyboard_model/personalize.py`)만 있음. DB에 접속하는 배치 코드는 넣지 않음.

### 5.4 HRV

```
mu = w * 개인 평균 + (1 - w) * 집단 평균
sd = w * 개인 표준편차 + (1 - w) * 집단 표준편차
w = n / (n + k),  k = 10
```

- 측정이 희소해 표준편차도 섞음. 키보드와 다른 점임.
- 개인 기준선은 "낮음"으로 판정된 정상 측정만으로 계산함. 5건 미만이면 집단 기준을 씀.
- 코드: `ppg_hrv/stress_judge.py`.

## 6. PPG/HRV 모델 (MAUS)

### 6.1 데이터

- MAUS (Beh & Wu, 2021). 22명, N-back 과제. 심전도, 손끝 PPG, 손목 PPG, 피부전도.
- 손끝 PPG를 고른 이유: 폰 카메라로 잴 수 있음. 논문에서도 손끝 66.7%, 손목 59.9%.
- 라벨: 0-back과 휴식은 저부하(0), 2-back과 3-back은 고부하(1).

### 6.2 저자 공개 피처 확인과 재처리

- 저자 공개 피처(2분 창, 13개)는 변동성과 주파수 지표이고 평균 심박은 없음.
- 저자 피처 13개로 LOSO AUC 0.724, 변동성 3개(SDNN, RMSSD, pNN50)만으로 0.712.
- SDNN은 고부하에서 감소(52.5 → 42.3, MW p < 0.001).

같은 원신호를 2분 창으로 재처리해 저자 값과 비교

| 피처 | 저부하 (저자 / 재처리) | 고부하 (저자 / 재처리) |
|---|---|---|
| SDNN | 52.5 / 56.3 | 42.3 / 44.6 |
| RMSSD | 32.6 / 39.2 | 31.6 / 32.3 |
| pNN50 | 12.8 / 16.2 | 11.0 / 10.3 |

- 크기와 방향이 일치함. 창별 1:1 대조까지는 하지 않음.
- 재처리 심박 69, 심전도 67.

1분 창으로 다시 만든 이유

| 선택 | 근거 | 결과 |
|---|---|---|
| 창 60초 | 사용자가 견딜 수 있는 측정 시간. 시간 영역 지표는 60초에서 쓸 수 있음 | 서비스와 같은 창 |
| 서비스와 같은 처리 코드 | `ppg_pipeline.py`로 MAUS 원신호를 재처리 | 학습 피처와 서비스 출력이 같은 분포 |
| 평균 심박 추가 | 공개 피처에 없음. 원신호에서 계산 | 0.657 → 0.722 |
| 시간 영역만 | 주파수 영역은 60초에서 불안정 | 4피처 |

- 창 길이에 따른 변화(60초 대비): SDNN은 30초에서 -10%, 120초에서 +11%. 평균 심박, RMSSD, pNN50은 ±0~3%.

### 6.3 신호 처리

1. 대역 통과: 2차 Butterworth, 0.5~4Hz, 위상 지연 없는 양방향 필터.
2. 256Hz로 업샘플. 30fps 원신호는 RR 간격 해상도가 약 33ms라 RMSSD가 뭉개짐.
3. 품질 확인: 왜도, 심박 대역 파워 비율, 추정 심박 40~180 bpm.
4. 피크 검출: 최소 간격과 prominence 조건.
5. RR 간격 계산.
6. 아티팩트 처리: 300~1500ms 밖, 국소 중앙값에서 25% 넘게 벗어난 박동을 표시하고 보간.

| 피처 | 식 |
|---|---|
| `mean_rr` | mean(RR) |
| `mean_hr` | 60000 / mean(RR) |
| `sdnn` | std(RR, ddof=1) |
| `rmssd` | sqrt(mean(ΔRR²)) |
| `pnn50` | mean(\|ΔRR\| > 50) × 100 |

- Poincaré SD1, SD2와 주파수 영역 지표도 계산하지만 모델에는 쓰지 않음.

### 6.4 피처 4개

| 피처 | 의미 | 비고 |
|---|---|---|
| `mean_hr` | 평균 심박 | MAUS 공개 피처에 없어 추가 |
| `rmssd` | 연속 간격 차의 RMS | |
| `sdnn` | 간격의 표준편차 | |
| `pnn50` | 연속 차가 50ms를 넘는 비율 | |

- 후보 6개(위 4개, SD1, SD2) 모두 집단 간 유의(MW p < 0.001), 단일 AUC 0.57~0.60.
- SD1은 RMSSD와, SD2는 SDNN과 r = 1.00이라 뺌. 6피처 0.721, 4피처 0.722.
- 제외: nn50, sdsd(중복), tinn, tri_index(긴 기록 필요), 주파수 영역 6종.

### 6.5 데이터 검증 (757창, 22명)

- 분할: LOSO. 창 단위로 나누면 같은 사람이 양쪽에 들어감.
- Nested CV(바깥 LOSO, 안쪽 5겹)로 규제 강도를 조정해도 기본 LOSO와 같음.

### 6.7 모델, 구간, 성능

- 개인별 z-score, 표준화, 로지스틱 회귀(`class_weight="balanced"`).

## 7. 두 모델의 결합

| MAUS, 이 저장소 모델 | 실험실 | 22명 | LOSO AUC | 0.72 |

- 행동 신호만으로는 0.6대가 상한에 가까움. 성능을 올리는 것은 데이터 양보다 신호의 종류임.

## 10. 한계

1. HRV 모델의 0.722와 0.579는 접촉식 손끝 PPG, 실험실 값임. 폰 카메라, 일상 환경에서 같은 성능이 나오는지 확인하지 못함.
2. 두 층의 결합은 데이터로 확인하지 못함. SWELL과 MAUS는 서로 다른 사람의 데이터임.
3. 새 사용자의 첫 HRV 측정 성능은 0.58임.
4. HRV 성능의 상당 부분이 평균 심박에서 옴(+0.065). 평균 심박은 카페인, 자세, 신체 활동으로도 오름.
5. 라벨은 자가보고임. 수집 데이터 결과는 통계적으로 유의하지 않음(31명, p = 0.10).
6. 31명, 라벨 157건은 가능성 확인 수준의 규모임.
7. 테스터가 한 집단에서 모집되어 코딩 작업과 영문 입력 비중이 높음.
8. 알람 규칙(30분, 20개, 63)과 HRV 구간 경계(38.5, 65.7)는 초기값임.

## 11. 운영 확인 (2026-11-09 조회)

- 1분 창 누적 414,771건. 수집이 계속되고 있었음.
- 개인 기준선 38명분. 갱신 시각이 모두 당일 04:00으로 같아 야간 배치가 실행됨을 확인함.
- PPG 측정 저장은 0건. 판정 코드와 저장 구조는 준비되었으나 측정값을 저장하는 연결이 끝나지 않음. PPG 실측이 없는 이유임.

## 12. 관련 작업: 감정 분류 모델

스트레스 감지 뒤의 공감 대화에 쓴 분류 모델. 이 저장소에는 코드가 없음.

- 모델: KcELECTRA(beomi/KcELECTRA-base-v2022) 미세조정. 6종(기쁨, 당황, 분노, 불안, 상처, 슬픔).
- 데이터: AI허브 공감형 대화, 28,638세션, 약 221,000발화. 세션 단위로 나눔.
- 성능: 다중 클래스 ROC-AUC 0.93, 정확도 0.71. 5겹 세션 교차검증 0.9311 ± 0.0008. 시드 2개 0.9301, 0.9320.
- 비교: KcELECTRA 0.9301, klue/bert-base 0.9255. 감성대화 말뭉치를 합치면 라벨 체계가 달라 성능이 떨어져 쓰지 않음.
- 감정별 F1: 기쁨 0.86, 분노 0.74, 상처 0.69, 당황 0.66, 슬픔 0.63, 불안 0.62.
- 라우팅: 확률 0.42 미만이면 중립, 기쁨이면 긍정, 부정 감정이고 확률 0.55 이상이면 해당 감정 전략, 그 외는 공통 전략. 위기 신호는 분류를 거치지 않고 전문기관 안내로 보냄.
- 대화 내용은 서버에 저장하지 않음.
