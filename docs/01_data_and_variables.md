# 데이터 출처와 변수 정의

## 1. 데이터 출처

| 구분 | 데이터 | 규모 | 용도 | 저장소 포함 여부 |
|---|---|---|---|---|
| 키보드·마우스 | SWELL-KW (Koldijk et al., ICMI 2014) | 지식노동자 25명, 분당 행동 집계 | 모델 학습, 검증 | 미포함 (배포처에서 직접 받아야 함) |
| 손가락 PPG | MAUS (IEEE DataPort, DOI 10.21227/q4td-yd35) | 22명, 256Hz 손가락 PPG, N-back 과제 | 모델 학습, 검증 | 미포함 (재배포 제한) |
| 서비스 수집 | 케어퐁 테스터 대상 직접 수집 | 분석 대상 31명, 유효 라벨 약 157건 | 키보드·마우스 모델 검증, 개인화 기준선 | 미포함 |
| 데모 | 합성 PPG 파형, 예시 입력값 | 8건 | 실행 확인 | 포함 |

- SWELL-KW 사용 파일: `Behavioral-features - per minute.xlsx`, 시트 `SWELLdata`.
- MAUS 사용 파일: `Data/Raw_data/<피험자>/inf_ppg.csv`, `inf_resting.csv`.
- 서비스 수집 데이터는 2026년 10월 테스트 기간의 키·마우스 1분 창과 자가보고 응답임. 개인 건강 관련 기록이라 원본과 집계본 모두 공개하지 않음.
- 손가락 PPG는 측정 기능까지 만들었으나 분석할 만큼의 실측이 모이지 않음.
- 자가보고 질문은 "스트레스를 받았는지"(예/아니오)와 1~5점 척도임. 트리거는 아침(morning), 무작위(random), 과부하 감지(spike) 세 가지.
- 저장소의 `validation_samples.json`과 `demo/`의 입력은 사람에게서 측정한 값이 아님. 추론 함수 검산과 실행 확인을 위해 만든 값임.

## 2. 키보드·마우스 모델 변수

### 입력 16피처 (1분 창 기준)

| 구분 | 변수 | 정의 |
|---|---|---|
| 키보드 | `SnKeyStrokes` | 전체 키 입력 수 |
| 키보드 | `SnChars` | 글자 키 수 |
| 키보드 | `SnSpecialKeys` | 특수 키 수 |
| 키보드 | `SnDirectionKeys` | 방향 키 수 |
| 키보드 | `SnErrorKeys` | 백스페이스, Delete 수 |
| 키보드 | `SnShortcutKeys` | 단축키 수 |
| 키보드 | `SnSpaces` | 스페이스 수 |
| 키보드 | `CharactersRatio` | 글자 키 비율 |
| 키보드 | `ErrorKeyRatio` | 오류 키 비율 |
| 마우스 | `SnMouseAct` | 마우스 활동 수 |
| 마우스 | `SnLeftClicked` | 좌클릭 수 |
| 마우스 | `SnRightClicked` | 우클릭 수 |
| 마우스 | `SnDoubleClicked` | 더블클릭 수 |
| 마우스 | `SnWheel` | 휠 수 |
| 마우스 | `SnDragged` | 드래그 수 |
| 마우스 | `SnMouseDistance` | 이동 거리 |

- SWELL-KW 전체 172개 컬럼 중 컴퓨터 상호작용 18개가 후보였음.
- 앱 전환 2개(`SnAppChange`, `SnTabfocusChange`)는 창 제목에 접근해야 해서 제외함. 남은 16개를 전부 씀.
- 키 입력 내용은 변수에 없음. 종류별 개수와 비율만 씀.

### 라벨

- `y = 1`: 실험 조건이 시간 압박(T) 또는 이메일 방해(I)인 분.
- `y = 0`: 중립(N) 또는 휴식(R)인 분.
- 라벨은 "스트레스 요인이 주어진 조건"이며 참가자가 느낀 스트레스 점수가 아님.

### 판정 대상과 출력

- 활동 0 창(`SnKeyStrokes + SnMouseAct == 0`)은 판정하지 않음. 점수는 `None`.
- 스트레스 지수 = 보정 확률 x 100 (0~100).
- 단계: 50 미만 `normal`, 50 이상 63 미만 `observe`, 63 이상 `intervene`.
- 63은 ROC에서 Youden's J가 최대인 지점임.

## 3. PPG/HRV 모델 변수

### 입력 4피처 (60초 창 기준)

| 변수 | 정의 | 단위 |
|---|---|---|
| `mean_hr` | 평균 심박 | bpm |
| `rmssd` | 연속 RR 간격 차이의 제곱평균제곱근 | ms |
| `sdnn` | RR 간격 표준편차 | ms |
| `pnn50` | 연속 RR 차이가 50ms를 넘는 비율 | % |

- 파이프라인은 `sd1`, `sd2`, `lf`, `hf`, `lf_hf`도 계산하지만 모델 입력에는 쓰지 않음.
- 주파수 영역 지표는 측정이 120초 미만이면 `lf_reliable = False`로 표시함.
- 입력은 개인 기준선 대비 z-score로 바꿔 모델에 넣음.

### 라벨

- `label = 1`: 2-back, 3-back 과제 구간.
- `label = 0`: 0-back 과제 구간과 휴식(resting) 구간.

### 출력

- 점수 = 확률 x 100 (0~100, 정수).
- 판정: 38.5 미만 `deny`, 38.5 이상 65.7 미만 `observe`, 65.7 이상 `confirm`.
- 두 경계는 민감도와 특이도를 각각 0.85로 맞춘 지점임. Youden 컷은 49.
- `used_reference`: 개인 기준선 비중이 절반 이상이면 `personal`, 아니면 `coldstart`.

## 4. 개인화 변수

| 변수 | 정의 |
|---|---|
| `n` | 그 사용자의 평소 창 수(키보드) 또는 안정 측정 횟수(PPG) |
| `k` | 개인과 전체가 반반이 되는 지점. 키보드 300, PPG 10 |
| `w` | 개인 비중. `w = n / (n + k)` |
| `mu_eff` | `w * 개인평균 + (1 - w) * 전체평균` |
